# 重新生成应用图标

图标资源由一张线稿图生成，生成逻辑见 `tools/MakeIcon.java`。

## 为什么要用脚本而不是直接放 PNG

源图是**白底 JPEG**。若直接缩放当图标，白底会变成不透明方块：
放在深色壁纸上会看到一个刺眼的白方块，边缘还会有锯齿。

脚本做了三件必须做的事：

1. **白底转透明** —— alpha 由「像素到白色的距离」推导，
   抗锯齿边缘自然成为半透明，换任何底色都不露白边
2. **按内容裁剪** —— 去掉四周白边，再居中放入各密度画布，
   否则图案大小会随原图留白多少而变
3. **按安全区缩放** —— 系统会把 108dp 画布放大 `108/72` 倍后再裁切，
   图案必须相对**中心 72dp 可见区**定尺寸。若按整个 108dp 画布定尺寸，
   图案会被放大后裁掉一圈（这个坑踩过一次）

## 用法

只需要 JDK 17，无需任何第三方依赖（用 JDK 自带的 ImageIO，单文件源码模式运行）：

```bash
# 在项目根目录执行
java tools/MakeIcon.java <源图.jpg> app/src/main/res

# 也可以省略第二个参数，默认就是 app/src/main/res
java tools/MakeIcon.java icon-source.jpg
```

脚本会打印识别到的墨色、内容裁剪框和各密度输出尺寸，便于核对。
若源图不是白底，会给出警告。

脚本会输出到 `app/src/main/res/`：

| 输出 | 用途 |
|---|---|
| `mipmap-{m,h,xh,xxh,xxx}dpi/ic_launcher_foreground.png` | 自适应图标前景（108dp 画布） |
| `mipmap-{m,h,xh,xxh,xxx}dpi/ic_launcher.png` | 传统方形图标（API 24/25） |
| `mipmap-{m,h,xh,xxh,xxx}dpi/ic_launcher_round.png` | 传统圆形图标（API 24/25） |

背景层是矢量，不需要生成：`app/src/main/res/drawable/ic_launcher_background.xml`。

## 检查生成结果

改完图标后建议确认图案没有被安全区裁掉：

脚本输出里会打印图案尺寸；把它除以「画布的 72/108」即为占可见区的比例，
应落在 **70%~80%**。小于 60% 显得太小，接近 100% 则会被系统遮罩裁到。

一个快速的自检方式：把生成的 `ic_launcher_foreground.png` 取中心
`72/108` 的区域，看图案是否完整落在里面。

## 换图标要注意

- **深色壁纸**：图案是深蓝线条，所以背景层固定用白色。
  如果换成浅色图案，记得把背景层一并改成深色，否则会看不见
- **修改后建议实机看一眼**：不同厂商的启动器遮罩形状不同
  （圆、方圆形、水滴形等），模拟器上正常不代表所有机型都正常
